Sobre o Trabalho

O trabalho utiliza código SQL para a criação de tabelas interconectadas que representam o funcionamento de uma loja de vendas de carros.

O banco de dados foi desenvolvido para relacionar informações como vendedores, comissões, clientes e modelos de carros, permitindo organizar e gerenciar os dados de forma estruturada e eficiente.
